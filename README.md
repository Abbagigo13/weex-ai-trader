# Abbagigo AI Trader

AI-powered trading intelligence platform built for the WEEX AI Wars II competition.

## Architecture

- React + Vite frontend
- FastAPI backend
- WEEX market data
- Strategy engine
- Risk engine
- AI analysis layer
- Trading execution layer

## Safety

The project starts in paper-trading mode.

Real trading is disabled by default.

```env
TRADING_ENABLED=false
PAPER_TRADING=true
